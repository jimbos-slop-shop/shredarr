# Security policy

## Supported versions

Only the latest release gets security fixes. Update with `docker compose pull shredarr && docker compose up -d
shredarr` before reporting.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/jschaef80/shredarr/security/advisories/new).

If that link says private reporting isn't turned on, open an issue that only says "security report, please contact
me". Put no details in it.

Include what you found, how to reproduce it, and the Shredarr version. Leave out real API keys, passwords and tracker
passkeys.

You'll get a reply once the report has been looked at. When a fix ships, the advisory is published with credit to you,
unless you'd rather stay anonymous.
